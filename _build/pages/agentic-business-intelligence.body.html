The deliverableEl entregable

A file, not a screenshot. Un archivo, no una captura.

Most "AI dashboard" tools produce an image or a hosted view inside their own product. That is a demo, not an asset — your BI team cannot version it, extend it, or fold it into an existing workspace, and you are renting access to your own analysis. La mayoría de las herramientas de "tableros con IA" produce una imagen o una vista alojada dentro de su propio producto. Eso es una demostración, no un activo — su equipo de BI no puede versionarlo, extenderlo ni integrarlo en un espacio existente, y usted alquila el acceso a su propio análisis.

The output here is a native Power BI project folder in Microsoft's own open formats. It opens in Desktop, lives in source control, and behaves like something an analyst built — because structurally, it is. Aquí la salida es una carpeta de proyecto nativa de Power BI en los formatos abiertos de Microsoft. CorrectnessCorrección

Three loops, then a floor you cannot fall through. Tres ciclos, y luego un piso del que no se puede caer.

A dashboard that opens with broken measures is worse than no dashboard, because someone has to debug generated DAX. Each loop validates a different failure class against the real data, and safe mode guarantees that a build always returns something valid. Un tablero que abre con medidas rotas es peor que ninguno, porque alguien tiene que depurar DAX generado. Cada ciclo valida una clase distinta de falla contra los datos reales, y el modo seguro garantiza que una construcción siempre devuelva algo válido.

LOOP 01

×2

Schema loopCiclo de esquema

The model's read of your data structure is checked against the actual source: do these table and column names exist, are the key columns real, do the inferred relationships hold? A confident misreading of the schema poisons everything downstream, so it is caught first. La lectura del modelo sobre su estructura se verifica contra la fuente real: ¿existen estas tablas y columnas, son reales las claves, se sostienen las relaciones inferidas? Una lectura errónea pero segura del esquema envenena todo lo demás, por eso se detecta primero.

LOOP 02

×2

Config loopCiclo de configuración

The dashboard design is cross-referenced against the validated schema. Every table reference, every column binding, and every column named inside a DAX expression must resolve to something that exists. A visual bound to an imagined column never reaches the builder. El diseño del tablero se contrasta con el esquema validado. Cada referencia de tabla, cada enlace de columna y cada columna nombrada dentro de una expresión DAX debe resolver a algo existente. Un visual ligado a una columna imaginada nunca llega al constructor.

LOOP 03

×3

Validator loopCiclo de validación

DAX expressions are executed against real data samples, which is the only way to catch semantic errors that parse perfectly — a sum over a text column, a divide against a column that is zero in production. Three retries, then safe mode. Las expresiones DAX se ejecutan contra muestras reales, la única forma de detectar errores semánticos que analizan bien — una suma sobre una columna de texto, una división contra una columna que en producción vale cero. Tres reintentos, luego modo seguro.

Safe mode: the guaranteed floorModo seguro: el piso garantizado

If all three retries on the validator loop are exhausted, the system does not return a broken file and it does not return an error. It generates a minimal dashboard — cards and tables only, no charts — that is guaranteed to open and be correct. A user always gets something they can work from, and the failure is logged for a human to look at rather than silently swallowed. Si se agotan los tres reintentos del ciclo de validación, el sistema no devuelve un archivo roto ni un error. Genera un tablero mínimo — solo tarjetas y tablas, sin gráficos — garantizado para abrir y ser correcto. El usuario siempre recibe algo con qué trabajar, y la falla se registra para revisión humana en lugar de tragarse en silencio.
